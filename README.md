# Guia do Iniciante – Criação de Personagens em D&D 5ª Edição
## Projeto de IA Generativa

## 📒 Descrição
Este projeto consiste na criação de um **guia introdutório completo para criação de personagens em Dungeons & Dragons 5ª Edição**, desenvolvido com o apoio de **Inteligência Artificial Generativa**.

O objetivo principal foi transformar um conjunto de regras complexas, originalmente apresentadas de forma técnica no Livro do Jogador, em um material **didático, acessível e organizado**, voltado especialmente para **iniciantes**, sem perder a fidelidade às mecânicas do sistema.

O conteúdo aborda desde os primeiros passos da criação de personagem até o detalhamento aprofundado de **raças, classes, progressão por nível, subclasses e antecedentes**, sempre com explicações claras e exemplos conceituais.

## 🤖 Tecnologias Utilizadas
### ChatGPT (OpenAI)
Utilizado para:
- Organização estrutural do guia
- Escrita do conteúdo original
- Explicação didática das regras
- Reescrita e adaptação de conceitos técnicos para iniciantes
- O grosso desse Readme que você está lendo nesse exato segundo

### Leonardo AI
Utilizado para:
- Geração da imagem ilustrativa do projeto
- Apoio visual ao material final (1 imagem logo no começo do material)

## 🧐 Processo de Criação
O processo de criação seguiu as seguintes etapas:

## 1. Definição do escopo
Foi definido que o projeto teria como foco um **guia para iniciantes**, mas com profundidade suficiente para também servir como material de consulta.

## 2. Estrutura baseada no Livro do Jogador
O conteúdo foi organizado seguindo a **ordem oficial de criação de personagens** apresentada no Livro do Jogador, garantindo coerência com o sistema original.

## 3. Geração e refinamento com IA
A IA foi utilizada para:
- Explicar conceitos complexos de forma simples
- Detalhar progressões de classes nível por nível
- Descrever subclasses, diferenças mecânicas e estilos de jogo
- Garantir consistência terminológica ao longo do texto

## 4. Preocupação com originalidade (“natty”)
Todo o texto foi escrito de forma **original**, evitando cópia ou paráfrase direta do material oficial, focando em interpretação, explicação e reorganização do conhecimento.

## 5. Criação visual
A arte do projeto foi criada com auxílio do Leonardo AI para complementar visualmente o guia.

### Detalhamento de:

## 💭 Reflexão
Criar um conteúdo “natty” com IA generativa foi um dos principais desafios do projeto. Em vez de simplesmente reproduzir regras existentes, foi necessário **interpretar, reorganizar e explicar** conceitos já conhecidos de uma forma nova, clara e original.

O uso da IA mostrou-se especialmente eficiente como **ferramenta de apoio criativo e pedagógico**, acelerando o processo de escrita e ajudando a manter consistência, mas sempre exigindo curadoria humana para garantir clareza, fidelidade ao sistema e originalidade do texto final.

O projeto demonstra que a IA generativa pode ser usada não apenas para automatizar tarefas, mas para **criar materiais educacionais de qualidade**, quando utilizada de forma consciente e responsável.
